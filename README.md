# ByteBerry-Expenses

💸 API REST para gestión de gastos personales con autenticación JWT. Clean Architecture, TypeScript, PostgreSQL/Prisma, CRUD completo. Validación OAuth2 via JWKS. Docker multi-arch ARM64/AMD64. Event sourcing y Saga pattern.
